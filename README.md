# ShopItemsTgBot
Телеграм бот @PodarokkApiBot для управления товарами в магазине [PodarokkShop](https://vk.com/podarokk.shop)

Доступ к боту ограничен.

## Бот может:
- Обновить цену товаров в сообществе VK
  
  Цена на гелий меняется несколько раз в год. При изменении цены на гелий цену товаров необходимо пересчитывать по формулам и редактировать каждый товар, что вручную долго. В боте можно указать новую цену за порцию гелия и он пересчитает и обновит цены всех композиций в соответствии с новой ценой.
- Выгрузить список товаров в файл для последующей загрузки на другие платформы. Реализованы файлы для загрузки в 2gis и yandex.
